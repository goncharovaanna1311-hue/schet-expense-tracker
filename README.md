# Счёт — трекер расходов

Самостоятельный веб-MVP по [публичному заказу Cross Platform Expense Tracker App](https://www.freelancer.com/projects/flutter/Cross-Platform-Expense-Tracker-App). Заказчик не участвовал в разработке и не принимал результат. Реализована часть исходного задания.

## Возможности

- Добавление, редактирование и удаление расходов в рублях.
- Категории, журнал с датами, выбор месяца, общая сумма и средний расход.
- Распределение расходов по категориям.
- Сохранение в localStorage и CSV-экспорт выбранного месяца.
- Суммы в целых копейках, проверка ввода и экранирование пользовательского текста.

## Запуск

Нужен Node.js 22 или новее; внешних зависимостей нет.

```sh
npm start
```

Команда запускает сервер. Откройте http://127.0.0.1:4173. На Windows можно запустить start.cmd. Если порт занят предыдущей демонстрацией, остановите её сочетанием Ctrl+C.

```sh
npm test
```

Команда запускает проверки расчётов, хранения и пользовательских сценариев с подменённым DOM.

## Структура

- dist/ — статическое приложение, готовое для статического хостинга.
- dist/core.mjs — даты, деньги, агрегация и CSV.
- dist/storage.mjs — отдельный адаптер хранения.
- dist/app.mjs — интерфейс и обработчики действий.
- tests/ — автоматические проверки.

## Ограничения

Это локальный веб-MVP: нет нативных iOS/Android-сборок, банковских интеграций, профиля и облачной синхронизации. Валюта — RUB. Упомянутый в заказе PDF не был доступен и не использовался. Очистка браузера удаляет данные; экспортируйте CSV. Импорт не реализован. Одновременные изменения в нескольких вкладках могут перезаписать друг друга.

Отдельный ключ хранения не переносит автоматически записи из общей витрины трёх трекеров. Внешний шрифт загружается из Google Fonts, при недоступной сети используется системный.

Реальная браузерная и мобильная проверка в этой среде не выполнена. Исходники: https://github.com/goncharovaanna1311-hue/schet-expense-tracker (закрытый репозиторий). Публичная веб-демонстрация пока не опубликована.
